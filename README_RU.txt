СБОРКА APK БЕЗ УСТАНОВКИ ПРОГРАММ НА ПК (Windows 11)

В этом архиве уже лежит твой HTML внутри Android-проекта. APK собирается бесплатно в облаке GitHub Actions.

1. Создай/войти в аккаунт на https://github.com
2. Нажми + (вверху справа) -> New repository.
3. Имя репозитория, например, my-android-app. Выбери Public (так проще для первого раза), нажми Create repository.
4. На странице пустого репозитория нажми "uploading an existing file".
5. Распакуй этот ZIP на ПК. Открой папку TornadoAppProject. Перетащи ВСЕ файлы и папки ИЗ НЕЁ на страницу GitHub upload (включая папку .github; если скрытая папка не перетащилась, загрузи .github/workflows/build-apk.yml отдельно через создание файла с таким путём).
6. Внизу нажми Commit changes.
7. Открой вкладку Actions. Если попросит, разреши Actions.
8. Выбери "Build Android APK" слева. Нажми Run workflow -> зелёную кнопку Run workflow.
9. Подожди, пока запуск завершится зелёной галочкой.
10. Открой завершённый запуск и внизу страницы найди Artifacts -> android-apk. Скачай ZIP и распакуй.
11. Внутри будет app-debug.apk. Перешли APK на телефон и открой его для установки. Android может попросить разрешить установку из этого источника.

ВАЖНО:
- При сборке нужен интернет, но само приложение после установки работает офлайн.
- Не переименовывай HTML в APK: APK собирается автоматически из проекта.
- Название приложения меняется в app/src/main/AndroidManifest.xml, в android:label="Моё приложение".
- Идентификатор приложения задаётся в app/build.gradle (applicationId). Меняй его только до установки/публикации.
- Иконка, которую меняет HTML-админка, пока меняет изображение внутри приложения, а не значок Android на рабочем столе.
- Хранилище карточек использует IndexedDB; WebView настроен на локальный адрес appassets.androidplatform.net, без внешнего сайта. Импорт/выбор изображений использует системный выбор файлов.
